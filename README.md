step_coder — инструмент для сжатия STEP-файлов (ISO 10303) с целью экономии токенов при обучении и генерации LLM.

Результаты сжатия на тестовой выборке из 15 файлов:
Среднее сжатие - 38.1%
Максимальное сжатие - 54.1%
Минимальное сжатие - 21.9%

Что именно происходит?
- Сжатие ключевых слов до 2-буквенных кодов (словарь 178 сущностей)
- Сжатие последовательных ссылок: `#14, #15, #16` → `#14-#16`
- Умное сжатие чисел: удаление хвостовых нулей + RLE для повторяющихся цифр
- Удаление незначащих имён сущностей (`'Cone'` → `''`)
- Удаление лишних пробелов и переносов строк
- Автоматическое определение кодировки входного файла (поддержка cp1250, cp1251, UTF-8 и др.)
- Полная обратимость — декодер восстанавливает исходный файл

Дополнительные установки:
pip install chardet

Использование:
Кодирование (STEP → S-STEP): python encoder.py input.step output.sstep
Декодирование (S-STEP → STEP): python decoder.py input.sstep output.step

Струкура
step_coder/
├── encoder.py          # Кодировщик
├── decoder.py          # Декодировщик
├── dictionary.txt      # Словарь замен
└── README.md
